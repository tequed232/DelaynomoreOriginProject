# 使用 DeepSeekHarness

> 本节以 DeepSeekHarness（下文简称 DSH）为例，介绍如何认识一个 Agent Harness 项目，并为后续接入模型、插件和 MCP 做准备。

- 难度：🟢 入门
- 建议学习时间：15～25 分钟
- 状态：具体安装命令和界面截图待根据仓库当前版本实测补充

## 学习目标

- 理解 DeepSeekHarness 在本教程中的位置。
- 了解运行前需要确认的环境和配置。
- 能够区分 Harness、模型服务、Plugins、Skills 与 MCP。

## 1. DeepSeekHarness 是什么？

在本教程中，DeepSeekHarness 是用于组织 Agent 工作流程的运行环境。它不是模型本身，也不等同于某一个 API 服务。

可以先用这个关系理解：

```text
用户任务
   │
   ▼
DeepSeekHarness（运行与协调）
   ├── 模型 API：提供语言模型能力
   ├── Plugins：扩展可调用的功能
   ├── Skills：提供可复用的任务方法
   └── MCP：连接外部工具与数据服务
```

不同项目版本的实际模块和命名可能不同，正式教程应以 DSH 仓库当前实现为准。

1. 阅读项目 README 和许可证。

## 4. 初学者需要区分的五个概念

| 名称 | 主要作用 |
|---|---|
| Harness | 组织 Agent 的运行、状态、工具和控制流程 |
| 模型 API | 提供模型推理服务的访问入口 |
| Plugin | 为运行环境增加具体扩展能力 |
| Skill | 描述某类任务如何稳定、重复地完成 |
| MCP | 约定客户端与外部工具/数据服务之间的连接方式 |

它们可能在一个项目中协同工作，但不是同一种东西。
