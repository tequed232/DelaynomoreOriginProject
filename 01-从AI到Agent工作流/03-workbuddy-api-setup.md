# 在腾讯 WorkBuddy 中导入模型 API

> 本节介绍模型 API 接入时需要理解的参数，并以腾讯 WorkBuddy 作为操作对象。

- 难度：🟢 入门
- 建议学习时间：10～20 分钟
- 状态：WorkBuddy 当前版本的具体入口、支持协议和字段名称待实测

## 学习目标

- 理解 API Key、Base URL、模型名称等参数。
- 知道“模型服务商”和“使用模型的客户端”之间的关系。
- 能够安全地配置并验证模型连接。

## 1. 先理解 API 配置

一般情况下，接入兼容 OpenAI API 格式的模型服务可能需要以下信息：

| 参数 | 含义 | 示例 |
|---|---|---|
| API Key | 访问服务的凭据 | `YOUR_API_KEY` |
| Base URL | API 服务入口 | `https://example.com/v1` |
| Model | 服务端提供的模型标识 | `model-name` |
| API 格式 | 客户端与服务端采用的接口协议 | 以客户端支持情况为准 |

以上均为字段解释，不代表 WorkBuddy 一定使用这些确切字段名，也不代表任意 API 服务都能直接兼容。

## 2. 配置前先核对服务商信息

从模型服务提供方获取：

- 官方 API 文档。
- API Key。
- API Base URL。
- 可用模型的准确 ID。
- 支持的接口格式。
- 计费方式、速率限制和地区限制。

不要根据网页聊天产品的名称猜测 API 模型 ID。网页订阅和 API 计费通常也需要分别确认。

## 3. 在 WorkBuddy 中配置

> 以下为操作流程框架。正式发布前，应使用当前 WorkBuddy 版本核实菜单名称、字段和支持范围，并替换为真实截图。

1. 打开腾讯 WorkBuddy。
2. 找到模型或服务提供方配置入口。
3. 查看客户端是否支持自定义 API 或兼容接口。
4. 按客户端要求填写服务商信息。
5. 填入 API Key、Base URL 和模型 ID。
6. 保存配置。
7. 选择刚配置的模型，发送一个简单测试请求。
8. 检查是否收到正常回复。

如果 WorkBuddy 当前版本没有开放自定义 API 接入入口，不应通过猜测隐藏配置或修改未知文件来代替官方支持方式。应在教程中明确说明该版本限制。

## 4. 测试连接

建议使用一个不包含隐私信息的简单问题，例如：

> 请只回复：API 连接测试成功。

验证时观察：

- 是否成功建立连接。
- 是否出现认证错误。
- 是否提示模型不存在。
- 是否出现接口格式不兼容。
- 是否触发额度或速率限制。

## 5. 常见问题

| 现象 | 可能原因 | 检查方向 |
|---|---|---|
| 401 / Unauthorized | Key 错误、失效或未正确传递 | 检查凭据和服务商账户 |
| 404 | Base URL 或接口路径不匹配 | 对照官方 API 文档 |
| Model not found | 模型 ID 不正确或无权限 | 核对模型清单 |
| 429 | 超出速率或额度限制 | 查看服务商配额 |
| 连接超时 | 网络、代理或服务端问题 | 检查网络与服务状态 |
| 返回格式异常 | API 协议或客户端兼容性问题 | 核对接口格式 |

## 6. 安全提醒

- 不要在视频录制、截图或日志中暴露完整 API Key。
- 不要把 API Key 写入 Markdown、代码仓库或公开 Issue。
- 不要把个人账号密码当作 API Key。
- 费用和速率限制应以服务商当前说明为准。
- 测试完成后检查日志，确认没有泄露凭据。

## 本节小结

配置模型 API 的关键不是只复制一个 Key，而是让客户端、接口格式、服务地址和模型 ID 正确匹配。
